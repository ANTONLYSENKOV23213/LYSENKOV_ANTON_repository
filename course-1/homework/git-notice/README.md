# Домашнее задание по Git

## Содержание

- commands.txt — основные команды Git и примеры их использования.
- commits-rules.txt — правила Conventional Commits.
- task.md — описание задания.
- README.md — описание проекта.

## Цель проекта

Изучить базовые команды Git, научиться сохранять изменения
в коммитах и правильно оформлять сообщения коммитов.
